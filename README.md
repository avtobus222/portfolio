# Портфолио: Мария Дегтяренко

Сайт-портфолио: геймдизайн, 3D и 2D, Unity. Обычный HTML, CSS и JavaScript, без сборки и без установки пакетов.

## Структура проекта

```
portfolio/
├── index.html            разметка главной и подключение файлов
├── css/                  стили, по одному файлу на часть сайта
├── js/
│   ├── data/             ВСЕ ТЕКСТЫ И ДАННЫЕ (здесь правишь содержимое)
│   ├── core/             помощники и всплывающие окна
│   ├── home/             главная: цифры, роли, 3D-карусель
│   ├── pages/            внутренние страницы (по файлу на страницу)
│   ├── games/            мини-игры, кривая ценности, симулятор
│   └── app/              переходы между разделами, эффекты, клавиатура
├── models/               3D-модели (.glb)
├── images/               картинки и скриншоты
├── videos/               видео (mp4)
└── docs/                 документы (PDF)
```

Порядок подключения файлов в `index.html` важен: сначала данные, потом ядро, главная, страницы, игры и приложение.

## Где что править

| Что менять | Файл |
|---|---|
| Роли на главной, навыки, почта | `js/data/config.js` |
| 3D-модели и 2D-работы | `js/data/projects.js` |

| Кейсы по геймдизайну | `js/data/gamedesign.js` |

| Текст на главной, под заголовком | `index.html` |
| Цвета и шрифты | `css/base.css` |

## Как добавить 3D-модель

1. Экспорт из 3ds Max: `File → Export → Export…`, тип `GL Transmission Format (*.glb)`. Имя латиницей, без пробелов, например `cup.glb`.
2. Положи файл в папку `models/`.
3. Открой `js/data/projects.js` и впиши путь в поле `model`:

```js
{ title:"Кружка", desc:"Моя первая модель", model:"models/cup.glb", cat:"3D", tags:["3ds Max","PBR"] },
```

Карточка модели появляется на сайте только когда поле `model` заполнено. Модели показывает библиотека `model-viewer`, она подключена в `index.html`.

Быстрая проверка без кода: открой страницу «3D и 2D» и перетащи файл `.glb` мышкой на большое окно просмотра.

## Как добавить 2D-работу

Положи картинку в `images/` и добавь строку в `js/data/projects.js` с `cat:"2D"`:

```js
{ title:"Окно меню", desc:"Что сделано", img:"images/menu.jpg", model:"", cat:"2D", tags:["Photoshop","UI"] },
```

## Как добавить проект Unity

В `js/data/unity.js`, список `UNITY_WORKS`. Заполни нужные поля, остальные оставь пустыми `""`:

- `img` — скриншот из `images/`
- `video` — файл из `videos/` (mp4, лучше до 20–30 МБ)
- `youtube` — ссылка на видео, оно откроется прямо на сайте
- `links` — кнопки со ссылками, например `[["GitHub","https://..."]]`

Блок «Мои проекты в Unity» скрыт, пока нет ни одного `img`, `video` или `youtube`.

## Запуск на компьютере

Двойной клик по `index.html` открывает сайт, но браузер не даёт загрузить `.glb` с диска. Чтобы модели показывались, запусти сайт через локальный сервер:

1. Открой папку в VS Code.
2. Поставь расширение **Live Server**.
3. Правая кнопка по `index.html` → **Open with Live Server**.

## Публикация на GitHub Pages

1. На github.com создай репозиторий (например `portfolio`, Public).
2. Загрузи в него **всё содержимое** папки `portfolio` вместе с папками `css`, `js`, `models`, `images`, `docs`. Через `Add file → Upload files` можно перетащить папки целиком.
3. `Settings → Pages → Branch: main / (root) → Save`.
4. Через 1–2 минуты сайт откроется по адресу `https://ТВОЙ_НИК.github.io/portfolio/`.

Имена файлов и папок на GitHub чувствительны к регистру: `models/Cup.glb` и `models/cup.glb` для сервера разные файлы.

## Что не выкладывать

Отчёты из университета с ФИО преподавателя и номером группы на сайт не добавлялись. Если положишь в `docs/` файлы с личными данными (телефон в резюме и т.п.), они станут публичными вместе с репозиторием.
